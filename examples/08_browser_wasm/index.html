DuckPipe · Phase 4

DuckPipe, running entirely in this tab

No install. No server. Whatever file you pick never leaves this page.

This loads a real DuckDB engine and DuckPipe's own, completely unmodified source (task.py/dag.py/fingerprint.py/state.py/scheduler.py) into a WebAssembly sandbox via Pyodide, then runs the exact same duckpipe.run(...) call the CLI uses. The pipeline (pipeline.py, open it) profiles whatever tabular file you give it and caches each task's result, fingerprinted the same way as every other DuckPipe run — reload this page and run again with the same file, and every task reports skipped.
